เห็นโค้ด Arduino ทำงานทีละบรรทัด

ทำนายก่อนว่าโค้ดจะทำอะไร แล้วเดินโค้ดดูค่าตัวแปร สถานะขา และไฟบนบอร์ดเสมือนไปพร้อมกัน ผลการคำนวณตรงกับบอร์ด Arduino Uno จริง

เริ่มที่บทที่ 2สำหรับอาจารย์
void loop() {
digitalWrite(13, HIGH);
delay(500);
digitalWrite(13, LOW);
delay(500);
}
ขา 13 LOW
เวลาจำลอง 0 ms
  1. ทำนายอ่านโค้ดแล้วคิดก่อนว่าเงื่อนไขจะจริงหรือเท็จ หรือตัวแปรจะได้ค่าเท่าใด
  2. เดินโค้ดกดทีละบรรทัด ดูแถบสีเหลือง ค่าในหน่วยความจำ และตารางติดตามค่า
  3. แก้แล้วลองใหม่ภารกิจสุดท้ายของทุกตัวจำลองให้แก้โค้ดเองแล้วตรวจผล

บทที่ 2 ไมโครคอนโทรลเลอร์และการเขียนโปรแกรม Arduino

ใช้ได้ตั้งแต่ครั้งที่ 2 ไม่ต้องต่อวงจร

// ตัวอย่างที่ 2.1 ถึง 2.10
ตัวอย่างในบทที่ 2

โค้ดตัวอย่างทุกตัวในเอกสาร เดินทีละบรรทัดหรือคัดลอกไปวางใน Tinkercad ได้ทันที

11 ตัวอย่าง คัดลอกโค้ดได้
 void loop() { count++; }
setup() และ loop()

อะไรทำครั้งเดียว อะไรทำซ้ำ และตัวแปรที่ประกาศใน loop() หายไปเมื่อใด

3 ภารกิจ
 float f1 = a / b;
ตัวแปรและการหาร

หารจำนวนเต็มตัดเศษ และ int 16 บิตที่ล้นเมื่อคูณเลขใหญ่

3 ภารกิจ
 if (a && b) { ... }
ตัวดำเนินการ && และ ||

สร้างตารางความจริงด้วยสวิตช์ 2 ตัว และดูว่าเมื่อใดไม่ต้องคำนวณด้านขวา

3 ภารกิจ บอร์ดเสมือน
 else if (temp > 60)
คำสั่ง if / else if / else

ไฟเตือนอุณหภูมิ 3 สี ค่าบนขอบเงื่อนไข และลำดับของเงื่อนไขที่ผิด

3 ภารกิจ บอร์ดเสมือน
 for (int i = 1; i <= 4; i++)
คำสั่งวนซ้ำ for

ค่าเริ่มต้น การตรวจเงื่อนไข และการเปลี่ยนค่าในแต่ละรอบ

3 ภารกิจ
 while (level < 20)
คำสั่งวนซ้ำ while

เติมน้ำจนถึงระดับที่ต้องการ และลูปที่ไม่มีวันจบ

3 ภารกิจ

บทที่ 3 สัญญาณดิจิทัล

มีบอร์ดเสมือน ปุ่มกด และกราฟสัญญาณ

// ตัวอย่างที่ 3.1 ถึง 3.8
ตัวอย่างในบทที่ 3

โค้ดตัวอย่างทุกตัวในเอกสาร พร้อมวงจรบนบอร์ดเสมือน คัดลอกไปวางใน Tinkercad ได้ทันที

8 ตัวอย่าง คัดลอกโค้ดได้
 digitalWrite(LED_BUILTIN, HIGH);
digitalWrite และ delay

กราฟสัญญาณที่ขาตามเวลาของโปรแกรม Blink และ delay ที่หายไป

3 ภารกิจ กราฟสัญญาณ
 pinMode(7, INPUT_PULLUP);
digitalRead และ pull-up

INPUT เทียบกับ INPUT_PULLUP และขาที่ปล่อยลอยจนอ่านค่าสุ่ม

3 ภารกิจ
 lastState == HIGH && state == LOW
กดติดกดดับ

จำสถานะปุ่มรอบก่อน และปัญหาการเด้งของปุ่มจริง

4 ภารกิจ ใช้หลังทำแบบฝึกหัดข้อ 4
 attachInterrupt(..., countISR, FALLING);
อินเทอร์รัปต์

นับชิ้นงานด้วยการอ่านใน loop() เทียบกับ ISR และผลของการเด้ง

บทที่ 4 สัญญาณอนาล็อก

ตัวอย่างในบทที่ 4

4 ตัวอย่าง คัดลอกโค้ดได้
 float volt = adc * 5.0 / 1023.0;
analogRead และวงจรแบ่งแรงดัน

จากแรงดันเป็นค่า ADC การลืมใส่ .0 และตำแหน่งของ photoresistor

4 ภารกิจ

ไฟอัตโนมัติและฮิสเทอรีซิส

ตัวอย่างในบทที่ 5

3 ตัวอย่าง คัดลอกโค้ดได้

เวลาที่เสียงเดินทางไปกลับ กรณีไม่พบวัตถุ และความละเอียดของการวัดอุณหภูมิ

analogWrite (PWM)

ตัวจำลองทุกตัวใช้ตัวแปลภาษา Arduino ตัวเดียวกัน ผลการคำนวณถูกทดสอบเทียบกับไมโครคอนโทรลเลอร์ ATmega328P จริงแล้วทุกบรรทัด ตัวจำลองแต่ละตัวมีเฉพาะโค้ด อุปกรณ์บนบอร์ด และภารกิจ จึงเพิ่มตัวใหม่ได้โดยไม่ต้องเขียนโปรแกรมส่วนอื่น

อาจารย์วิชาอื่นที่ต้องการฝากตัวจำลองของวิชาตนเองไว้ที่นี่ ติดต่อผู้ดูแลได้ทาง github.com/me-buu/arduino-simulator วิธีเพิ่มตัวจำลองอยู่ในไฟล์ README.md

หลักการออกแบบ

  • เปิดหน้ามาแล้วรันภารกิจ 1 ได้ทันที ไม่มีตัวเลือกให้ปรับ
  • ทุกภารกิจมีคำถาม 1 ข้อ ให้คิดคำตอบก่อนดูผล
  • ใช้ในคาบไม่เกิน 10 นาที บนโน้ตบุ๊กหรือ iPad
  • ไม่ได้ใช้แทน Tinkercad แต่แสดงสิ่งที่ Tinkercad มองไม่เห็น
